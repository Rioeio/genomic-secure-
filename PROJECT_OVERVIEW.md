# Med-Link: Project Report (Overview)

Refer to `project_report.md` in the brain artifact directory or read the executive summary below.

## What is Med-Link?
Med-Link is a decentralized federated research platform enabling multi-institutional genomic and clinical studies without centralizing sensitive patient health records.

## Key Pillars:
1. **Privacy-Preserving Computation**: Only differentially-private model gradients cross institutional firewalls.
2. **Multi-Ancestry Equity**: Stratified performance monitoring across European (EUR), South Asian (SAS), and African (AFR) populations.
3. **Dual-Domain Versatility**: Seamlessly executes across multi-locus genomic profiles and OHDSI OMOP CDM clinical EHR data (diagnoses and medication exposures).
4. **Healthcare Interoperability**: Direct output alignment with HL7 FHIR R4 MolecularSequence and OHDSI OMOP CDM v5.4.
